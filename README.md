# Arena TCG — Catálogo de Pokémon

Identificação: Matheus Pares Pagotto

Projeto demonstrativo para estudo e testes. Interface baseada no protótipo de listagem fornecido. Os estados de erro e carregamento foram elaborados como aproximações, pois não foram fornecidos protótipos específicos desses estados.

## Executar

Requer Node.js 20 ou superior.

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite. A listagem depende de acesso à PokeAPI. O projeto usa uma consulta de listagem, cache de dez minutos e tentativa manual em caso de erro. Não usa autenticação nem rotas adicionais.

## Evidências

As capturas devem ser feitas após executar o projeto. Veja prints/LEIA-ME.txt. Nenhuma captura ou teste de execução foi fabricado.
